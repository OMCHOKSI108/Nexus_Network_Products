================================================================================
                              PROJECT OVERVIEW
================================================================================

Nexus Network Products is a comprehensive B2B e-commerce platform specializing 
in brass fittings, cable gland accessories, pressure gauge parts, pneumatic 
components, and air conditioning/refrigeration parts. The platform provides a 
modern, user-friendly interface for businesses to browse, order, and manage 
their industrial parts procurement.

================================================================================
                           TECHNOLOGY STACK
================================================================================

FRONTEND:
- Framework: React 18.3.1 (with Vite 6.0.5)
- UI Library: Tailwind CSS 3.4.17
- Routing: React Router DOM 7.1.1
- HTTP Client: Axios 1.7.9
- Build Tool: Vite
- Deployment: Vercel

BACKEND:
- Runtime: Node.js 
- Framework: Express.js 4.21.2
- Database: MongoDB (Mongoose ODM 8.9.4)
- Authentication: JWT (jsonwebtoken 9.0.2)
- Password Hashing: bcryptjs 2.4.3
- File Upload: Multer 1.4.5-lts.1
- Cloud Storage: Cloudinary 2.6.0
- Email: Nodemailer 6.9.17
- Rate Limiting: express-rate-limit 7.5.0
- Security: Helmet 8.0.0, express-mongo-sanitize 2.2.0
- CORS: cors 2.8.5
- Environment: dotenv 16.4.7
- Development: Nodemon 3.1.11

AI/LLM INTEGRATION:
- LLM Provider: Groq (groq-sdk 0.9.0)
- RAG Service: Custom implementation with vector search
- Chatbot: Interactive AI assistant with product recommendations

================================================================================
                           API ENDPOINTS
================================================================================

USER AUTHENTICATION (POST /api/users/):
- POST   /register         Register new user
- POST   /login            User login
- GET    /profile          Get user profile (Protected)
- PUT    /profile          Update profile (Protected)
- POST   /forgot-password  Request password reset OTP
- POST   /verify-otp       Verify OTP code
- POST   /reset-password   Reset password with OTP
- POST   /logout           User logout

PRODUCTS (GET /api/products/):
- GET    /                 Get all products (with filters)
- GET    /:id              Get product by ID
- GET    /category/:cat    Get products by category
- GET    /search           Search products
- POST   /                 Create product (Admin)
- PUT    /:id              Update product (Admin)
- DELETE /:id              Delete product (Admin)

CART (GET /api/cart/):
- GET    /                 Get user cart (Protected)
- GET    /count            Get cart item count (Protected)
- POST   /                 Add item to cart (Protected)
- PUT    /:itemId          Update cart item quantity (Protected)
- DELETE /:itemId          Remove item from cart (Protected)
- DELETE /                 Clear entire cart (Protected)

ORDERS (GET /api/orders/):
- POST   /                 Create new order (Protected)
- GET    /                 Get user orders (Protected)
- GET    /:id              Get order details (Protected)
- PUT    /:id/cancel       Cancel order (Protected)
- GET    /admin/all        Get all orders (Admin)
- PUT    /admin/:id/status Update order status (Admin)

CHATBOT (POST /api/chatbot/):
- POST   /message                    Send message to chatbot
- GET    /conversation/:sessionId    Get conversation history
- DELETE /conversation/:sessionId    Delete conversation
- POST   /action/add-to-cart        Add product to cart from chatbot
- POST   /feedback                   Submit chatbot feedback

ADMIN (POST /api/admin/):
- POST   /login            Admin login
- GET    /verify           Verify admin token
- POST   /logout           Admin logout

================================================================================
                           DATABASE MODELS
================================================================================

USER MODEL:
- username (String, required, validated)
- name (String)
- email (String, required, unique, validated)
- password (String, required, hashed)
- phone (String)
- company (String)
- gstNumber (String)
- address (Object with full shipping details)
- profileImage (String)
- resetOtp (String for password reset)
- resetOtpExpires (Date)
- lastLogin (Date)
- timestamps (createdAt, updatedAt)

PRODUCT MODEL:
- name (String, required)
- description (String, required)
- price (Number, required)
- category (String, required)
- image (String - Cloudinary URL)
- stockQuantity (Number, default: 0)
- inStock (Boolean, default: true)
- sku (String, unique)
- specifications (Object)
- minOrderQuantity (Number, default: 1)
- isActive (Boolean, default: true)
- timestamps

CART MODEL:
- userId (ObjectId, ref: User, required)
- items (Array of):
  - productId (ObjectId, ref: Product)
  - productName (String)
  - quantity (Number)
  - price (Number)
  - image (String)
  - subtotal (Number)
- totalAmount (Number)
- totalItems (Number)
- timestamps

ORDER MODEL:
- user (ObjectId, ref: User, required)
- orderNumber (String, unique, auto-generated)
- items (Array of order items)
- totalAmount (Number, required)
- shippingAddress (Object)
- status (String: pending, confirmed, processing, shipped, delivered, cancelled)
- paymentMethod (String)
- paymentStatus (String)
- trackingNumber (String)
- notes (String)
- timestamps

CONVERSATION MODEL (Chatbot):
- userId (ObjectId, ref: User, nullable)
- sessionId (String, required, indexed)
- messages (Array of):
  - role (String: user, assistant, system)
  - content (String)
  - timestamp (Date)
  - metadata (Object)
- context:
  - isAuthenticated (Boolean)
  - lastActivity (Date)
  - relevantProducts (Array of Product refs)
  - cartInteraction (Boolean)
  - orderInteraction (Boolean)
- status (String: active, archived, ended)
- timestamps
