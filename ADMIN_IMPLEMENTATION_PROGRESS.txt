🎯 INTEGRATION REQUIREMENTS
=======================================================================

1. Register new routes in server.js:
   ```javascript
   const adminPanelRoutes = require('./routes/adminPanelRoutes');
   app.use('/api/admin-panel', adminPanelRoutes);
   ```

2. Add IP blocking middleware globally:
   ```javascript
   const { checkBlockedIP } = require('./middleware/ipBlocker');
   app.use(checkBlockedIP);
   ```

3. Add activity logging to existing routes:
   - Login: activityLogger('LOGIN')
   - Logout: activityLogger('LOGOUT')
   - Cart actions: activityLogger('ADDED_TO_CART'), etc.
   - Orders: activityLogger('PLACED_ORDER')

4. Update admin authentication to set role/email:
   - Ensure req.user includes _id and email

=======================================================================
🏗️ ARCHITECTURE DECISIONS
=======================================================================

✅ Separate namespace: /api/admin-panel/* (vs /api/admin/*)
   - Avoids conflicts with existing admin routes
   - Clear separation of concerns

✅ Non-blocking audit logging
   - Uses setImmediate to log after response
   - Doesn't slow down main operations

✅ Soft delete by default
   - Users marked as isDeleted=true
   - Permanent delete requires query param

✅ Audit middleware pattern
   - auditLogger wraps routes
   - Automatically logs all admin actions
   - Captures success/failure

✅ Activity logging pattern
   - Similar to audit logging
   - Captures user actions
   - Device and IP tracking
